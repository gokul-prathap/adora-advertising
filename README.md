# Adora Advertising - Premium Portfolio Platform

A luxury, dark-mode-first advertising portfolio platform built with modern web technologies for Adora Advertising, a premium agency based in Bangalore specializing in fashion photography, ad shoots, reels, and luxury wedding rentals.

## 🌟 Features

- **Cinematic Hero Section** - Full-width background with glassmorphism navigation
- **Dynamic Portfolio Gallery** - Categorized filters for Fashion, Ad Shoots, Weddings, Product, and Modelling
- **Mobile-Optimized Reels Showcase** - Instagram-style vertical scroll experience
- **Premium Services Section** - Detailed cards for brand shoots, reels, and portfolio development
- **High-Conversion Contact Form** - Sleek lead generation optimized for luxury clients
- **Instagram Integration Ready** - Placeholder for Phase 2 social media integration

## 🎨 Design System

- **Color Palette**: Deep Charcoal (#121212), Gold/Champagne (#D4AF37), Clean White
- **Typography**: Playfair Display (luxury serif), Inter (modern sans-serif)
- **Aesthetic**: Luxury, minimalist, dark-mode first
- **Animations**: Framer Motion for cinematic transitions

## 🚀 Tech Stack

- **Frontend**: React 19 with TypeScript (Strict Mode)
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Video**: React Player
- **Performance**: Optimized for 90+ Lighthouse score

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/adora-advertising.git
cd adora-advertising
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```
